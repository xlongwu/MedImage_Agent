## 12. Regression Severity Classification

### Critical Regression — STOP, do not proceed

- GUI/manual node reaches `EXECUTION_SUBMITTED`
- `executor_called=true` for GUI reviewed execution request
- `provider=pywinauto` accepted
- PyWinAuto constructed or imported in non-test contexts
- Adapter sets `provider_call_allowed=true`
- Rejected output submitted to guard or calls provider
- Tier 1/2/3 action executes
- Screenshot / clipboard / mouse / keyboard / network enabled
- Rawdata or derivatives write enabled through GUI paths
- Full suite fails in any safety-critical test file

### High Regression — Investigate before proceeding

- Guard blocked response missing `provider_call_allowed=false`
- Safety flags missing from blocked/rejected response
- Mock adapter route exposes `raw_text` / `raw_json`
- Schema inconsistency breaks frontend or API consumer
- SPM / DPABI / GPU reviewed execution regression

### Medium Regression — Document and proceed if accepted

- `audit_id` behavior changes without documentation
- Error code naming changes without compatibility note
- Fixture count changes without fixture catalog update
- Test baseline count changes without `CURRENT_STATE.md` update

### Low / Expected Change — Normal development

- New tests added (count increase)
- Documentation-only updates
- New mock-only fixtures added with tests
- Response metadata added without changing safety semantics
