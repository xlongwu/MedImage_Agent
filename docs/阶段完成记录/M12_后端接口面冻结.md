# M12 Backend API Surface Freeze

> M12-RELEASE-T002 | Backend API inventory and contract freeze  
> Status: COMPLETE | Date: 2026-07-11

---

## 1. Executive Summary

This document freezes the current backend API surface for the MedImage Agent project. It classifies every endpoint as release, internal, or test-only, documents the input/output contracts, and records the capability flags and blocked capabilities.

**Key finding:** 7 API surfaces + 1 internal catalog identified (5 release, 1 blocked, 1 internal). All release surfaces are safe. No endpoint exposes real model inference, real GUI automation, or PyWinAuto. The GUI Agent APIs are mock-only and record-observation-only by contract.

## 3. Reviewed Execution API Contract

### POST `/api/execute-reviewed/*`

**Type:** Release API (guarded)  
**Real execution:** ✅ Guarded by 12-gate pipeline

| Aspect | Contract |
|------|------|
| Allowlist | 36 nodes (SPM:7, DPABI:20, GPU:9) |

| Bypass prevention | `approved=true` does not bypass allowlist |

## 4. GUI Agent API Contract

### POST `/api/gui-agent/sessions`

**Type:** Release API (guarded)  
**Real execution:** ❌ Mock-only

| Field | Constraint |
|------|------|
| `provider` | Must be `mock` — all others → HTTP 403 |
| `provider=pywinauto` | Blocked unconditionally |
| `provider=desktop/browser/manual` | Blocked unconditionally |
| `approved=true` | Does not bypass provider policy |
| Session state | `_created_at_ts`, `step_count` tracked |

### POST `/api/gui-agent/step`

**Type:** Release API (6-layer guarded)  
**Real execution:** ❌ Only `record_observation` allowed

| Guard Layer | Enforces |
|------|------|
| Provider gate | `provider=mock` only |
| Session validator | `gui_sandbox_mode=true`, `allowed_action_tiers=[0]` |
| Action tier classifier | `record_observation` → Tier 0 |
| Action validator | 17 checks; only `record_observation` passes |
| Stop-condition checker | Step limit, duration, emergency abort |
| Audit pre-create | `create_gui_audit_record()` before provider call |

| Blocked | Status |
|------|:---:|
| Tier 1 navigation (6 actions) | ❌ |
| Tier 2 interaction (6 actions) | ❌ |
| Tier 3 destructive (22 actions) | ❌ |
| `get_window_title` | ❌ |
| `list_windows` | ❌ |
| `screenshot_ephemeral` | ❌ |
| Screenshots | ❌ |
| Clipboard | ❌ |
| Mouse/keyboard | ❌ |
| Network | ❌ |
| Input/output paths | ❌ |

### POST `/api/gui-agent/sessions/{id}/abort`

**Type:** Release API  
**Effect:** Sets session state to aborted; blocks all future steps.

### GET/POST `/api/gui-agent/screenshot`

**Type:** Blocked  
**Status:** Not implemented or guarded; screenshots blocked by contract.

## 5. Mock Adapter API Contract

### GET `/api/gui-agent/mock-adapter/fixtures`

**Type:** Release API (read-only metadata)  
**Real execution:** ❌

| Exposed | Not Exposed |
|------|------|
| `fixture_id` | `raw_text` |
| `category` | `raw_json` |
| `expected_status` | `chain_of_thought` |
| `expected_reason` | `screenshot_bytes` |
| | `clipboard_contents` |
| | `credentials` |

### POST `/api/gui-agent/mock-adapter/step`

**Type:** Release API (mock-only, guarded)  
**Real execution:** ❌

| Mode | Behavior |
|------|------|
| Safe fixture + `submit_to_guard=true` | Adapter → guard → Mock provider → audit |
| Safe fixture + `dry_run=true` | Adapter only; no guard, no provider |
| Rejected fixture | `MODEL_ACTION_REJECTED`; no guard, no provider |
| Unknown fixture | `MOCK_MODEL_FIXTURE_NOT_FOUND` |
| Missing session (submission) | `MOCK_ADAPTER_SESSION_REQUIRED` |

**Invariants:**
- Adapter never sets `provider_call_allowed=true`
- Only `record_observation` can reach Mock provider
- Guard remains sole source of provider permission

## 7. Security Invariants

1. GUI/manual reviewed execution allowlist = **0**
2. `executor_called=false` for all GUI reviewed execution requests
3. No `gui_*` request reaches `EXECUTION_SUBMITTED`
4. `provider=mock` is the only allowed GUI provider
5. `provider=pywinauto` → HTTP 403
6. `approved=true` does not bypass provider policy
7. Only `record_observation` can execute
8. Adapter never sets `provider_call_allowed=true`
9. Guard is sole source of `provider_call_allowed_by_guard=true`
10. Mock adapter route does not bypass guard
11. Rejected fixtures never reach guard or provider
12. No raw data exposed in fixture catalog response
