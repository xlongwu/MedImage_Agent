## Summary

v0.3.0-rc1 is the Desktop MVP Release Candidate for MedImage Agent, a
deterministic Plan-then-Execute platform for rs-fMRI research.  This is
a research engineering platform — **not for clinical diagnosis or medical
decision-making**.

### FunRaw/T1Raw DICOM Support

Real DPABI/SPM-style FunRaw/T1Raw DICOM rawdata is now detected and validated
as read-only input.  Validated with 1104 DICOM files across 3 subjects and
6 subject-modality groups.

- **Data Readiness**: reports DICOM raw layout as `warning` (not `blocked`).
  DICOM callout banner, `image_validation` downgrade, NIfTI-only labels.
- **NIfTI QC**: correctly reports no NIfTI files (`image_count=0`).
  No synthetic `examples/synthetic_bids` fallback for configured real projects.
- **Conversion Dry-Run**: produces 6 BIDS/NIfTI mapping previews:
  `FunRaw/Sub_00[1-3]` → `sub-00[1-3]/func/sub-00[1-3]_task-rest_bold.nii.gz`
  `T1Raw/Sub_00[1-3]` → `sub-00[1-3]/anat/sub-00[1-3]_T1w.nii.gz`
  Status = `ready`, no blocking issues.
- **BIDS Validation**: fail is expected for raw DICOM before conversion.
  UI now explains this.

No DICOM conversion is executed.  No dcm2niix is called.  Rawdata is not modified.

## Known Limitations

- NIfTI viewer not included (metadata-only preview)
- No complete QC dashboard
- No report editor
- MATLAB/SPM/DPABI/GPU are contract-only in this release
- SPM realign is preparation-only (dry-run, wrapper skeleton, batch preview)
- **DICOM conversion is dry-run only**: mapping previews are generated but
  no files are written.  Real dcm2niix execution is not implemented and
  must go through safety contract design first.
- QC Dashboard cache is single-module prototype (NIfTI QC Snapshot only)
- BIDS Validation fail is expected for raw DICOM datasets before conversion
- Dataset Summary may not yet fully integrate DICOM counts from Data Readiness
- Electron app is unsigned (SmartScreen warning on first run)
- Windows-only packaging
- No auto-update
- **NSIS installer deferred**: makensis "Can't open output file" on this
  build environment.  Validated `win-unpacked` directory build only.
  NSIS installer and portable single-exe artifacts are pending a
  compatible build environment.

## Safety Architecture

- Rawdata read-only (`copy_mode: reference`, `rawdata_readonly: true`)
- Approval Gate mandatory for all file writes and execution
- Path traversal prevention (`path_safety.py`)
- Artifact path gating (`project_id + run_id + artifact_id`)
- Frontend isolation (HTTP APIs only, no filesystem access)
- GPU/MATLAB/SPM/DPABI gated (requires `approved=true` + environment opt-in)
- All services emit `safety_flags` confirming read-only / dry-run / no-external-tools
