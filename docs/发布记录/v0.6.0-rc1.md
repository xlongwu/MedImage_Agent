# v0.6.0-rc1 — Phase 6 Engineering Stabilization & End-to-End Validation

## Overview

v0.6.0-rc1 is the Phase 6 release milestone, consolidating engineering foundation,
enabling real DICOM-to-NIfTI conversion with dcm2niix, integrating preprocessing
stage management, and validating research algorithms with golden dataset tests.

## What's Changed

### Phase 6A — Repository Rules & CI Stabilization
- Fix ERROR_KB.yaml artifact conflict: migrated to `src/backend/app/resources/`
- Clarify docs/tasks/ lifecycle with README and template
- Fix AGENTS.md middleware table to match actual main.py registration order
- Update ADR-003, ADR-004, ADR-005 statuses to Accepted
- Strengthen CI: backend collection+tests, frontend typecheck+lint+test+smoke+build, desktop check
- Pin frontend dependencies from "latest" to specific versions (^19.2.5 etc.)

### Phase 6B — Real DICOM Conversion Pipeline
- dcm2niix runtime management with 4-layer fallback (env var → PATH → bundled → error)
- Enable real dcm2niix execution in `run_conversion_execute()` (shell=False, argv list)
- Conversion result validation (NIfTI existence, JSON sidecar, subject pairing)
- Post-conversion registration for preprocessing input
- Frontend partial status and mapping-level result display
- dcm2niix v1.0.20260416 confirmed in mamba environment

### Phase 6C — Preprocessing Pipeline Integration
- Full stage state machine: not_started → planned → running → succeeded / failed / blocked / metadata_only
- Stage execution with manifest persistence and recovery support
- SPM/MATLAB stages correctly blocked (MATLAB not available)
- Python/GPU stages planned for execution
- Input-output chain registration for pipeline consistency

### Phase 6D — Algorithm Validation & Golden Tests
- ALFF/fALFF: z-standardization option added
- Golden dataset tests for ALFF, ReHo, FC, Nuisance Regression (5 tests, tolerance < 1e-4)
- NumPy reference implementations for comparison

## Known Limitations

- MATLAB/SPM/DPABI stages blocked (MATLAB not installed locally)
- Preprocessing Python/GPU stages configured as metadata_only (require SPM-processed NIfTI input)
- Golden validation against DPABI/SPM deferred (MATLAB unavailable)
- Full E2E (DICOM → preprocessing → report) requires MATLAB for SPM stages
