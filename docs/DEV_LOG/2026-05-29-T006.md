### 新增

#### .github/workflows/ci.yml

两个独立 job，可并行：

| Job | 环境 | 步骤 |
|-----|------|------|
| backend | ubuntu-latest, Python 3.11 | checkout → pip install → pytest --tb=short |
| frontend | ubuntu-latest, Node 20 | checkout → npm ci → npm run build |

触发条件：
- push: main, master, develop
- pull_request: main, master, develop

设计要点：
- Node 使用 `npm ci`（有 package-lock.json）+ npm cache
- `working-directory: src/frontend` 避免 cd 复杂逻辑
- 不安装 MATLAB/SPM/DPABI/GPU/CuPy
- GPU 测试自动 skip（无 CuPy 时 pytest.skip）
