### 新增状态

| 状态 | 触发条件 |
|------|---------|
| `REVIEWED_EXECUTION_DISABLED` | `MEDIMAGE_ENABLE_REVIEWED_EXECUTION != "1"` |
| `CONFIRMATION_REQUIRED` | env 开启但 `confirm_execution != true` |
| `AUDIT_REQUIRED` | env 开启但 `persist_audit != true` |
| `PROJECT_CONFIG_REQUIRED` | `project_config_path` 缺失 |
| `PROJECT_CONFIG_INVALID` | `ProjectSettings.from_yaml()` 失败 |
| `PIPELINE_YAML_REQUIRED` | `write_pipeline_yaml != true` |
| `EXECUTION_PREFLIGHT_READY` | 所有 10 个 preflight 条件满足 |

### preflight 状态机

```
dry_run=false
  → env var gate          → REVIEWED_EXECUTION_DISABLED
  → confirm_execution     → CONFIRMATION_REQUIRED
  → persist_audit         → AUDIT_REQUIRED
  → project_config_path   → PROJECT_CONFIG_REQUIRED
  → ProjectSettings check → PROJECT_CONFIG_INVALID
  → validate_plan         → VALIDATION_FAILED
  → approval_gate         → APPROVAL_GATE_BLOCKED
  → adapt_reviewed_plan   → PLAN_ADAPTER_FAILED
  → policy check          → EXECUTION_POLICY_BLOCKED
  → write_pipeline_yaml   → PIPELINE_YAML_REQUIRED
  → YAML write            → PIPELINE_WRITE_FAILED
  → audit write           (already guaranteed)
  → EXECUTION_PREFLIGHT_READY
```

### 环境变量

```bash
MEDIMAGE_ENABLE_REVIEWED_EXECUTION=1
```

默认未设置 → `REVIEWED_EXECUTION_DISABLED`

### ProjectSettings 校验

使用 `ProjectSettings.from_yaml()` —— 不信任前端，不使用裸 `yaml.safe_load`。

### Audit 策略

- 中途 blocked → `event_type: "execution_blocked"`
- preflight 通过 → `event_type: "execution_requested"`
- `EXECUTION_PREFLIGHT_READY` 时 `executor_called: false`
