### 7 Failure Diagnostic Scenarios

| Scenario | Severity | Response |
|----------|:---:|------|
| GUI node reaches EXECUTION_SUBMITTED | CRITICAL | Investigate plan_adapter/allowlist; roll back |
| executor_called=true for GUI request | CRITICAL | Investigate preflight gate; roll back |
| PyWinAuto runs during smoke | CRITICAL | Stop immediately; unset env vars; investigate |
| Screenshot contains real pixels | CRITICAL | Delete artifact; investigate provider routing |
| Clipboard accessed | CRITICAL | Stop and investigate import chain |
| SPM/DPABI/GPU regression fails | HIGH | Do not proceed to closeout; investigate classification |
| Bypass appears fixed accidentally | MEDIUM | Check for unreviewed code changes; update docs |
