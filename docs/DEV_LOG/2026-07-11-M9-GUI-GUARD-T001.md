# M9-GUI-GUARD-T001: /api/gui-agent/* API Guard Design

**Date:** 2026-07-11

**Status:** COMPLETE

## Summary

Completed the API guard design for `/api/gui-agent/*`. This is the first task of the M9 GUI Guard Implementation phase, providing a comprehensive architecture for closing the known bypass gap where the GUI Agent API surface operates outside the reviewed execution pipeline.

## Key Design Decisions

### 14-Layer Guard Pipeline

```
Layer  1: Request Schema Validation
Layer  2: Session Declaration Validation
Layer  3: Provider Policy Gate
Layer  4: Target Application/Window Scope Gate
Layer  5: Action Declaration Validation
Layer  6: Action Tier Classifier
Layer  7: File/Path Scope Gate
Layer  8: Screenshot Policy Gate
Layer  9: Clipboard Policy Gate
Layer 10: Network Policy Gate
Layer 11: Approval / HITL Gate
Layer 12: Audit Log Pre-Create
Layer 13: Stop-Condition Checker
Layer 14: Provider Call Permission Token
```

### 13 Structured Error Codes

`GUI_GUARD_SCHEMA_INVALID`, `GUI_GUARD_SESSION_INVALID`, `GUI_GUARD_PROVIDER_BLOCKED`, `GUI_GUARD_REAL_PROVIDER_DISABLED`, `GUI_GUARD_ACTION_UNKNOWN`, `GUI_GUARD_ACTION_TIER_BLOCKED`, `GUI_GUARD_SCREENSHOT_BLOCKED`, `GUI_GUARD_CLIPBOARD_BLOCKED`, `GUI_GUARD_NETWORK_BLOCKED`, `GUI_GUARD_PATH_SCOPE_BLOCKED`, `GUI_GUARD_APPROVAL_REQUIRED`, `GUI_GUARD_STOP_CONDITION`, `GUI_GUARD_AUDIT_REQUIRED`

### Standardised Error Response Schema

```json
{
  "ok": false, "status": "GUI_GUARD_BLOCKED",
  "error_code": "GUI_GUARD_PROVIDER_BLOCKED",
  "provider_call_allowed": false,
  "desktop_touched": false, "screenshot_captured": false,
  "clipboard_accessed": false, "mouse_used": false, "keyboard_used": false,
  "audit_id": "audit_gui_..."
}
```

### Provider Policy Gate

MockGuiProvider: allowed by default, CI-safe, no real desktop. PyWinAutoGuiProvider: permanently blocked; requires future dedicated enablement contract beyond any single flag.

### Action Tier Classifier

29 actions classified. Initial guard allows only Tier 0 with provider=mock. Tier 1/2/3 remain blocked. 22 Tier 3 actions permanently blocked.

### Mock-Only Rollout

6-phase implementation: provider gate (T002) → session validator (T003) → action validator + classifier (T004) → audit + stop (T005) → mock tests (T006) → guard closeout.

### Fine-Tuned Agent Path

Model → Action Adapter → Normalized Schema → Guard → Provider. Provider never directly exposed. Raw coordinates rejected.
