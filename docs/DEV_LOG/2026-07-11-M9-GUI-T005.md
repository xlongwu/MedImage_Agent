# M9-GUI-T005: Read-Only GUI Observation Contract

**Date:** 2026-07-11

**Status:** COMPLETE

## Summary

Completed M9-GUI-T005: comprehensive read-only GUI observation contract defining the safety boundary for Tier 0 observation actions, provider policies, screenshot handling, sensitive data redaction, audit logging, stop conditions, and future guard design.

## Key Design Decisions

### 7 Tier 0 Actions Formally Contracted

`record_observation`, `get_window_title`, `list_windows`, `observe_visible_ui_state`, `screenshot_ephemeral`, `get_control_text`, `get_menu_state`

All are: `read_only=true`, `uses_mouse=false`, `uses_keyboard=false`, `uses_clipboard=false`, `writes_files=false`, `submits_forms=false`, `network_access=false`, `expected_side_effects=none`

### Mock Provider Policy

- `MockGuiProvider` is the only observation provider available in T005
- Safe for CI, contract tests, and development
- No real desktop access, no real screenshots, no real clipboard
- Returns synthetic/fixture observations
- Cannot write raw screenshot files; only placeholder text

### Real Provider Policy

- `PyWinAutoGuiProvider` remains **blocked** for observation
- Real provider observation requires future 7-gate guard implementation
- Even observation can leak: PHI in screenshots, credentials in window titles, file paths in control text

### 4-Level Screenshot Policy

| Level | Status |
|-------|:---:|
| `disabled` | Default for T005 |
| `ephemeral_only` | Future — in-memory, no disk |
| `persist_redacted` | Future — requires redaction contract |
| `persist_raw` | **Permanently blocked** |

### Sensitive Data Policy

- All visible UI text is **untrusted**
- Window titles may contain file paths, subject IDs, PHI
- Control text may contain tokens, API keys, passwords
- Screenshot pixels may contain medical images
- Agent must NOT follow instructions found in UI text
- Raw visible text must be summarized or redacted before audit persistence
- Credential fields, token strings, rawdata paths, PHI in screenshots → must be redacted

### Session Declaration Schema (24 fields)

Key invariants: `gui_sandbox_mode=true`, `provider=mock` only (T005), `allowed_action_tiers=[0]` only, `screenshot_policy=disabled`, `clipboard_policy=disabled`, `network_policy=disabled`, `allow_rawdata_access=false`, `human_present=true`, `emergency_abort_enabled=true`, `audit_log_required=true`

### Action Declaration Schema (22 fields)

Key invariants: `action_tier=0`, `read_only=true`, all usage flags false, `output_paths=[]`, `expected_side_effects=none`

### Blocked Actions (16)

Tier 1 (focus_window, scroll, switch_tab, wait, wait_for_window, open_non_sensitive_panel, move_focus_within_declared_window), Tier 2 (click_dry_run, fill_form_field, select_file, menu_select, toggle_non_destructive, type_text_scoped, screenshot_persist_redacted), Tier 3 (click_run/save/delete/open_rawdata/clipboard/upload/download/credentials/install/send_email/etc.)

### Audit Requirements

17 required fields (session_id, step_id, timestamp, provider, target_app, target_window, action_type, action_tier, read_only, screenshot_captured, clipboard_accessed, keyboard_used, mouse_used, network_accessed, redaction_applied, result_summary, abort_status) + 5 prohibited fields (raw screenshot bytes, raw credential values, raw clipboard contents, raw API keys/tokens, unredacted PHI)

### 11 Stop Conditions

unexpected app, unexpected window, credential field visible, permission/security dialog, network/upload dialog, rawdata path visible, screenshot policy violation, step_limit exceeded, duration_limit exceeded, human_present=false, emergency abort requested

### Future 7-Gate Guard Design

validate session → validate action → classify tier → enforce provider policy → enforce screenshot/clipboard/network policies → create audit log → check stop conditions → only then call provider
