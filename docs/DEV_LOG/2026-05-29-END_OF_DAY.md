## 关键架构演进

### 从 reviewed plan 到 pipeline execution 的安全链路已建立

```
用户 goal → LLM Planner (candidate plan)
  → Plan Review Console (人工 review + edit)
  → Plan Validator (后端重跑, 不信任前端)
  → Approval Gate (后端重跑, 不信任前端)
  → Plan Adapter (reviewed plan → executor pipeline dict)
  → Execution Policy (SPM/DPABI/GUI/unknown 阻断)
  → Pipeline Writer (atomic YAML 写入受控目录)
  → [未来] Pipeline Executor (dry_run=false, 尚未开放)
```
