# 开发日志 — 2026-05-29 (M1-T003)

## 任务：M1-T003 — 新增 ProjectSettings 统一配置层

### 背景

当前项目中有三处独立实现的 `_load_project_config()`：
- `pipeline_executor.py:20` — 独立版本
- `agent_plan.py:11` — 独立版本
- `routes.py:147` — 独立版本

三处代码几乎完全相同（yaml.safe_load + 文件存在检查），属于典型重复代码。
字段访问风格也不统一（直接下标 vs .get() 链）。

长期来看，LLM Planner、Plan Validator、Tool Catalog 等新模块都需要读取配置，
重复的 `_load_project_config` 会放大维护成本和安全风险。

### 新增模块

#### src/backend/app/config/__init__.py
导出 `ProjectSettings`，提供清晰的模块入口。

#### src/backend/app/config/settings.py

四个 dataclass：

| 类 | 字段 | required | default |
|---|---|---|---|
| RuntimeSettings | work_dir | ✅ | — |
| | log_dir | ✅ | — |
| | derivatives_dir | ❌ | `"./derivatives"` |
| | report_dir | ❌ | `"./reports"` |
| | matlab_command | ❌ | `"matlab"` |
| ThirdPartySettings | spm_dir | ✅ | — |
| | dpabi_dir | ✅ | — |
| SafetySettings | rawdata_readonly | ❌ | `True` |
| | allow_overwrite_derivatives | ❌ | `False` |
| | require_confirmation | ❌ | `True` |
| ProjectSettings | runtime / third_party / safety / source_path | — | — |

设计决策：
- 关键字段缺失 → `ValueError("Missing required field: ...")`
- YAML 语法错误 → `ValueError("Invalid YAML: ...")`（包装 yaml.YAMLError）
- YAML 非 dict → `ValueError("...must be a mapping/dictionary...")`
- SafetySettings 兼容两种命名：`require_confirmation` 和 `require_confirmation_for_matlab_run`
- `source_path` 记录来源文件以便审计
