## 实现

### MATLAB command 白名单

- ✅ `matlab`, `matlab.exe`, absolute paths
- ❌ shell metacharacters: `; & | \` $ > < \n \r`
- ❌ arguments / spaces
- ❌ non-matlab basenames
- ❌ path traversal `..`
- ❌ forbidden locations

### Third-party path 校验

- ❌ empty
- ❌ path traversal
- ❌ rawdata/derivatives/reports/work
- ❌ is-file
- ⚠️ nonexistent → warning (not error)
