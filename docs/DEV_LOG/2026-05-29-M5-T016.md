## 实现细节

### 新增状态 (3 个)

| 状态 | 触发条件 |
|------|---------|
| `SAFE_EXECUTION_POLICY_BLOCKED` | preflight 通过但含 GPU/contract 节点 |
| `EXECUTION_SUBMITTED` | `run_pipeline()` 调用成功 |
| `EXECUTION_FAILED` | `run_pipeline()` 抛异常 |

### safe allowlist 策略

第一版只允许 `allowed_python_nodes`：
- `create_synthetic_bids`, `data_inspection`, `environment_check`
- Python QC/report 节点
- Python 后处理节点

阻断：
- `allowed_gpu_nodes` → `SAFE_EXECUTION_POLICY_BLOCKED`
- `allowed_contract_nodes` → `SAFE_EXECUTION_POLICY_BLOCKED`
- 所有 blocked 类别（SPM/DPABI/GUI/manual/unknown/uncataloged）

### executor 调用条件

必须满足全部 12 个条件才调用 executor：

```
MEDIMAGE_ENABLE_REVIEWED_EXECUTION=1
confirm_execution=true
persist_audit=true
project_config valid
validate_plan ok
approval_gate ok
adapt_reviewed_plan ok
policy clean
safe allowlist pass
write_pipeline_yaml=true
pipeline YAML written
audit record written
```

### audit 顺序

1. audit 必须先于 executor 写入 (`execution_requested`)
2. audit 写入失败 → 不调用 executor
3. executor 成功后已有 audit record

### 执行流程

```
preflight all green
  → safe allowlist check
    → blocked → SAFE_EXECUTION_POLICY_BLOCKED
  → write audit record
    → fail → AUDIT_WRITE_FAILED
  → run_pipeline(project_config_path, pipeline_yaml_path)
    → success → EXECUTION_SUBMITTED + executor_result
    → exception → EXECUTION_FAILED
```
