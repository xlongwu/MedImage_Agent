# M9-GUI-T001: GUI/manual node inventory and threat model

**Date:** 2026-07-11

**Status:** COMPLETE

## Summary

Completed M9-GUI-T001: full GUI/manual node inventory, threat model, and safety boundary documentation for the MedImage Agent project.

## Key Discovery

The codebase already contains a **fully implemented GUI Agent subsystem** (`src/backend/app/runtime/gui_agent.py`) that:

- Supports two providers: `MockGuiProvider` (default, records intended actions without desktop control) and `PyWinAutoGuiProvider` (real Windows desktop automation via pywinauto — click, type_text, menu_select, screenshot, locate_window, wait)
- Has full API endpoints registered in `main.py` (`GET/POST /api/gui-agent/sessions`, step, screenshot, abort)
- Has a frontend configuration panel (`DesktopSettingsPanel.tsx`) with GUI provider selection
- Has integration tests (`test_gui_agent_runtime.py`, 3 tests) and API tests (`test_api_basic.py`)
- **Operates OUTSIDE the reviewed execution pipeline** — it bypasses plan_validator, approval_gate, plan_adapter, and execute_reviewed_routes

## Inventory

**Zero** GUI/manual nodes are registered in NODE_REGISTRY or in the reviewed execution allowlist. The Tool Catalog's `_fallback()` function infers `gui_` prefix → `manual_required=True`, `risk_level="high"`.

## Current Defense Layers

| Layer | Behavior | Status |
|-------|---------|:---:|
| Tool Catalog `_fallback` | `gui_` prefix → `manual_required=True` | ✅ active |
| `plan_adapter.classify_plan_nodes` | `gui_*` or `backend=gui-agent` → `blocked_gui_nodes` | ✅ active |
| `approval_gate.check_approval_gate` | `manual_required_nodes` non-empty → `MANUAL_REQUIRED_NODE` | ✅ active |
| `execute_reviewed._is_policy_blocked` | `blocked_gui_nodes` → blocked | ✅ active |
| `execute_reviewed._check_safe_allowlist` | Only allowlisted backends pass | ✅ active |

## Safety Gap Identified

The GUI Agent API (`/api/gui-agent/*`) is a **separate, un-gated execution path** that does not pass through the 12-gate reviewed execution pipeline. The `PyWinAutoGuiProvider` can control the real Windows desktop when `approved=true` and `provider=pywinauto`. This is documented as a known safety gap — no action taken in T001.
