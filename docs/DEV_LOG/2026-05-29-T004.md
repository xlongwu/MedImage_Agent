# 开发日志 — 2026-05-29 (M1-T004)

## 任务：M1-T004 — 验证并统一前后端启动方式

### 背景

发现前端代码默认连接端口 8765，而后端文档和 start.sh 使用端口 8000。这导致：
- 前端 `DEFAULT_API_BASE` 连接 `http://127.0.0.1:8765`，永远连不上后端
- `npm run dev:backend` 启动在 8765，与所有文档不一致
- Electron 主进程和 preload 也使用 8765
- 后端 `core/config.py` 默认端口也是 8765

### 8765 → 8000 变更清单

共修改 **12 处**（3 个文件各行多次出现）：

| 文件 | 变更 |
|------|------|
| `src/frontend/package.json` | `dev:backend` 端口 8765→8000 |
| `src/frontend/src/api.ts` | `DEFAULT_API_BASE` 8765→8000 |
| `src/frontend/src/App.tsx` | 错误提示文本 8765→8000 |
| `src/frontend/src/lib/api/client.ts` | 两处 base URL 8765→8000 |
| `src/frontend/src/components/workflow/DataUploadStep.tsx` | 错误提示文本 8765→8000 |
| `src/frontend/src/hooks/useAppState.ts` | 错误提示文本 8765→8000 |
| `src/frontend/electron/main.cjs` | `DEFAULT_API_PORT` 8765→8000 |
| `src/frontend/electron/preload.cjs` | `port` 8765→8000 |
| `src/backend/app/core/config.py` | `port` 默认值、环境变量、fallback 三处 8765→8000 |

环境变量覆盖能力完整保留：
- `MEDIMAGE_BACKEND_PORT` — 后端端口
- `MEDIMAGE_BACKEND_HOST` — 后端主机
- `MEDIMAGE_API_BASE_URL` / `VITE_API_BASE_URL` — 前端 API base URL
- Electron 通过 `MEDIMAGE_DESKTOP_API_BASE_URL` 覆盖
