## Key Deliverables

### GUI Action Taxonomy (29 actions across 4 tiers)

**Tier 0 — Read-Only Observation (7 actions):**
`record_observation`, `get_window_title`, `list_windows`, `observe_visible_ui_state`, `screenshot_ephemeral`, `get_control_text`, `get_menu_state`
- Default policy: mock allowed; session approval required for real provider; no persistence; no keyboard/mouse; no clipboard; audit required

**Tier 1 — Low-Risk Navigation (8 actions):**
`focus_window`, `locate_window`, `wait`, `wait_for_window`, `scroll`, `switch_tab`, `open_non_sensitive_panel`, `move_focus_within_declared_window`
- Default policy: session approval required; must stay within target window; no file writes; no clipboard; stop on unexpected window

**Tier 2 — Medium-Risk Interaction (7 actions):**
`fill_form_field_non_secret`, `select_file_under_scoped_directory`, `menu_select`, `toggle_non_destructive_option`, `click_dry_run`, `type_text_scoped`, `screenshot_persist_redacted`
- Default policy: session + action-plan + per-action confirmation; file path must be in file_scope; audit required

**Tier 3 — High-Risk / Blocked by Default (22 actions):**
`click_run`, `click_execute`, `click_submit`, `save_file`, `overwrite_file`, `delete_file`, `open_rawdata`, `launch_external_app`, `read_clipboard`, `write_clipboard`, `upload_file`, `download_file`, `network_submission`, `enter_credentials`, `accept_permission_dialog`, `accept_security_dialog`, `accept_license_dialog`, `install_software`, `send_email`, `send_message`, `unscoped_file_select`, `raw_screenshot_persist`
- Default policy: blocked by default; separate contract required; wildcard approval cannot authorize; `approved=true` insufficient

### Sandbox Declaration Schemas

- **GUI Session Sandbox Declaration**: 23 fields including `gui_sandbox_mode`, `provider`, `target_application`, `target_window`, `allowed_action_tiers`, `file_scope`, `screenshot_policy`, `clipboard_policy`, `network_policy`, `external_app_policy`, `duration_limit_seconds`, `step_limit`, `human_present`, `emergency_abort_enabled`, `audit_log_required`, `redaction_policy`
- **GUI Action Declaration**: 22 fields including `action_type`, `action_tier`, `target_application`, `target_window`, `parameters`, `input_paths`, `output_paths`, `uses_screenshot`, `uses_clipboard`, `uses_keyboard`, `uses_mouse`, `network_access`, `expected_side_effects`, `requires_per_action_confirmation`
- **Validation rules** pseudocode: `validate_gui_session_declaration()` rejects `gui_sandbox_mode=false`, `provider=pywinauto` without real provider policy, Tier 3 in allowed tiers, rawdata_access=true, unrestricted clipboard/network/screenshot

### Policy Classification Rules (Pseudocode)

`classify_gui_action()` maps any action to tier and blocked/approved status. All Tier 3 actions blocked unconditionally. Tier 2 requires per-action confirmation. `validate_gui_session_declaration()` enforces 12 session-level constraints.
