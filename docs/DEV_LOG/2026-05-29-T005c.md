### 修改

#### src/backend/app/api/routes.py

`_load_project_config()` 中新增 ProjectSettings 校验，异常包装为 HTTPException(400)：

```python
def _load_project_config(path: str) -> dict[str, Any]:
    from src.backend.app.config import ProjectSettings
    try:
        ProjectSettings.from_yaml(path)
    except FileNotFoundError as exc:
        raise HTTPException(status_code=400, detail=str(exc)) from exc
    except ValueError as exc:
        raise HTTPException(status_code=400, detail=str(exc)) from exc
    # 以下原有逻辑不变
    ...
    return yaml.safe_load(...)
```

关键差异 vs T-005a/T-005b：API 层将 `ValueError`/`FileNotFoundError` 包装为 `HTTPException(400)`，保持 API 响应格式一致。
