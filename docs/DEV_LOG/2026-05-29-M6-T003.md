### HIGH_RISK_BACKENDS

```python
HIGH_RISK_BACKENDS = frozenset({
    "matlab-spm", "matlab-dpabi", "dpabi", "matlab",

```

### Wildcard 新规则

| 节点类型 | Wildcard `["*"]` | 需要 |
|---------|:---:|------|
| Python-only | ✅ 允许 | — |
| matlab-spm | ❌ 阻断 | explicit node + `approved_backends=["matlab-spm"]` |
| dpabi | ❌ 阻断 | explicit node + `approved_backends=["dpabi"]` |

### 新增错误码

| Code | 含义 |
|------|------|
| `WILDCARD_APPROVAL_NOT_ALLOWED_FOR_HIGH_RISK_BACKEND` | wildcard 不能覆盖高风险 backend 节点 |
| `HIGH_RISK_NODE_REQUIRES_EXPLICIT_APPROVAL` | 必须在 approved_nodes 中显式列出 |
| `HIGH_RISK_BACKEND_REQUIRES_APPROVAL` | 必须在 approved_backends 中声明 |
