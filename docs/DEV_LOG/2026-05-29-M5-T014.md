## 实现细节

### 新增请求字段

```python
class ExecuteReviewedRequest(BaseModel):
    write_pipeline_yaml: bool = False  # ← 新增
```

### 新增状态

| 状态 | 含义 |
|------|------|
| `PIPELINE_WRITE_REQUIRES_AUDIT` | `write_pipeline_yaml=true` 但 `persist_audit=false` |
| `PIPELINE_WRITE_FAILED` | writer 抛异常 |

### pipeline_yaml response 结构

```json
{
  "would_write": true,   // 前置条件通过时
  "written": false,      // write_pipeline_yaml=false 或 写入失败
  "path": null,          // 写入成功时为 YAML 路径
  "requires_audit": true // 始终 true
}
```

### 执行顺序

```
1. dry_run=false → DRY_RUN_ONLY
2. validate_plan → VALIDATION_FAILED
3. check_approval_gate → APPROVAL_GATE_BLOCKED
4. adapt_reviewed_plan → PLAN_ADAPTER_FAILED
5. policy check → EXECUTION_POLICY_BLOCKED
6. write_pipeline_yaml=true + persist_audit=false → PIPELINE_WRITE_REQUIRES_AUDIT
7. write_pipeline_yaml=true + persist_audit=true → write_reviewed_pipeline_yaml()
   ├─ 成功 → DRY_RUN_OK
   └─ 失败 → PIPELINE_WRITE_FAILED
```

### Audit 集成

- `dry_run_result` 包含 `pipeline_yaml` summary
- audit record 写入前已完成 pipeline_yaml summary 的计算
