# M9-GUI-GUARD-T003: Session Declaration Validator Implementation

**Date:** 2026-07-11

**Status:** COMPLETE

## Summary

Implemented the session declaration validator — Layer 2 of the 14-layer GUI Agent API guard pipeline. This adds T003 policy enforcement on top of the T002 provider policy gate, validating 18 session-level safety fields before any GUI session is created.

## Production Code Changes (3 files)

### MODIFIED: `src/backend/app/runtime/gui_agent_guard.py`

- Added 12 new error codes (session/sandbox/target/tier/file/screenshot/clipboard/network/external_app/human/emergency/audit)
- Added `_FILE_SCOPE_FORBIDDEN_SEGMENTS` + `_is_path_safe_for_file_scope()` helper
- Added `validate_gui_session_declaration()` — 18 checks against T003 policy:
  - Sandbox mode, provider presence, target scope
  - Action tiers (Tier 0 only), file scope safety
  - Rawdata/derivatives access (must be false)
  - Screenshot/clipboard/network policies (must be disabled)
  - External app policy (must be declared_target_only)
  - Duration/step limits, human present, emergency abort, audit, redaction

### MODIFIED: `src/backend/app/api/gui_agent_routes.py`

- Added `_guard_session()` helper — maps Pydantic model fields to validator kwargs
- Integrated into `POST /api/gui-agent/sessions` after provider gate
- Maps `target_app` → `target_application` for validator compatibility

### MODIFIED: `src/backend/app/api/models.py`

- Extended `GuiAgentSessionRequest` with 18 session declaration fields
- All fields have safe defaults for backward compatibility with existing mock calls
- Pydantic-level validation on duration/step limits (ge/le constraints)
