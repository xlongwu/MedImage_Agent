# 开发日志 — 2026-05-29 (T-0008)

## 任务：T-0008 — 修复 CI 剩余 8 个 backend 测试失败

### 修复 1：error_classifier KB 路径（7 tests）

**根因**：`error_classifier.py` 和 `error_kb_validator.py` 使用硬编码相对路径：
```python
Path("memory/global/ERROR_KB.yaml")
```
本地 Windows（pytest 7.4）CWD 恰好是项目根，路径解析成功。CI Linux（pytest 9.0）下 `Path.exists()` 返回 False → 空 KB → 所有模式匹配失败。

**修复**：
- `error_classifier.py`：新增 `_resolve_kb_path()` 函数，优先级：
  1. `MEDIMAGE_ERROR_KB_PATH` 环境变量
  2. `__file__` 推导项目根目录（`parents[3]`） + `memory/global/ERROR_KB.yaml`
  3. `Path.cwd()` fallback
- `error_kb_validator.py`：删除重复的 `_load_error_kb`，从 `error_classifier` import

### 修复 2：background_task_manager 原子写入（1 test）

**根因**：`_write_status()` 使用非原子 `path.write_text()`，后台线程写入时主线程读取 → 读到空/半写入文件 → `JSONDecodeError`。

**修复**：
- `_write_status()`：写入 `.tmp` 文件后 `Path.replace()` 原子替换
- 新增 `_read_status()`：处理文件不存在/为空/JSON 损坏/非 dict 四种情况，返回 None
- `get_task_status()` 和 `list_tasks()` 使用 `_read_status()`
