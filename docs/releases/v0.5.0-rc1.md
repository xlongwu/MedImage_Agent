# v0.5.0-rc1 Release Notes

## Summary

v0.5.0-rc1 delivers the complete Phase 5 preprocessing pipeline: a staged, sandbox-isolated, metadata-tracked DICOM-to-first-level-derivatives workflow with dry-run planning, env-gated execution, output registration, and validation reporting. No group statistics, classification, or clinical diagnosis capability is included. DPABI remains disabled. All external-tool execution is sandbox-gated and requires explicit environment flags.

## Major Features

### Phase 5 Preprocessing Pipeline (DICOM → FC)

| Stage | Dry-run | Sandbox Exec | Output Reg | Backend |
|---|---|---|---|---|
| Slice Timing + Realign | ✅ | ✅ (SPM/MATLAB) | ✅ | SPM |
| Coregistration + Normalization | ✅ | ✅ (SPM/MATLAB) | ✅ | SPM |
| Smoothing | ✅ | ✅ (SPM/MATLAB) | ✅ | SPM |
| Nuisance Regression | ✅ | ✅ (Python) | ✅ | Python |
| Temporal Filtering | ✅ | ✅ (Python) | ✅ | Python |
| ALFF/ReHo | ✅ | ✅ (Python) | ✅ | Python |
| Functional Connectivity | ✅ | ✅ (Python) | ✅ | Python |

- Every stage supports: dry-run batch preview → sandbox copy → execution → output registration → next-stage handoff
- All Python-only stages use optional numerical computation with metadata-first fallback
- All SPM/MATLAB stages require explicit env flags for execution
- Sandbox isolation: inputs copied, outputs written only under execution directory

### Frontend Workflow

- Converted BIDS handoff panel with subject/BOLD/T1w counting
- Preprocessing run workspace creation and Python-only preflight
- DPARSFA-style plan preview (15 stages)
- Feature-gated sandbox execution panels for all SPM/MATLAB stages
- Stage output registration buttons chaining stage-to-stage
- Advanced preprocessing validation dashboard with stage summaries and safety flags
- Pipeline report export (JSON + Markdown)
- All execution buttons require explicit confirmations

### Backend Endpoints

60+ endpoints covering:
- DICOM conversion review, release readiness, public execute (env-gated)
- Preprocessing input registration from converted BIDS
- Preprocessing run workspace CRUD + Python-only preflight
- Dry-run planning for all 7 major stages
- Sandbox execution for all 7 major stages (env-gated)
- Output registration for all 7 major stages
- Pipeline validation and report export

## Safety Boundaries

- ✅ All NIfTI/SPM/MATLAB execution is sandboxed (copied inputs only)
- ✅ Rawdata never modified
- ✅ Converted BIDS input never modified
- ✅ Previous-stage outputs never modified during registration
- ✅ All execution env-gated with explicit opt-in flags
- ✅ No `shell=True` anywhere
- ✅ No DPABI execution enabled
- ✅ Python-only stages use metadata-first fallback when deps unavailable
- ✅ Frontend execution buttons feature-flag gated
- ✅ Pipeline report is metadata-only (no raw image data)
- ✅ Research use only — not for clinical diagnosis

## Metadata-Only Limitations

- **ReHo**: Computation not yet implemented; metadata-only placeholder
- **Nuisance Regression**: Falls back to metadata-only when nibabel/numpy unavailable
- **Temporal Filtering**: Falls back to metadata-only when scipy unavailable
- **ALFF**: Simplified implementation (voxel std on filtered data)
- **FC**: Voxel-subset correlation (n_max=1000), atlas-optional

## Known Limitations

2. Nuisance regression may be metadata-only without nibabel/numpy
3. Real MATLAB/SPM execution requires local MATLAB + SPM installation with env flags

5. Group statistics not implemented
6. Classification not implemented
7. DPABI disabled
8. No clinical diagnosis capability
9. Desktop packaging not validated in RC1
