# SPM Smoke Manual Validation Guide

> M6-T004c | `spm_smoke_test` reviewed execution — 手动验证

**状态**: 手动 smoke — 需要真实 MATLAB/SPM 环境。不进入 CI。
**允许的节点**: 仅 `spm_smoke_test` — 所有 subject-level SPM 仍阻断。

---

## 一、前置条件

| 条件 | 说明 |
|------|------|
| MATLAB 已安装 | `matlab` 或 `matlab.exe` 可执行 |
| SPM12 已安装 | `spm_dir` 指向 SPM 根目录 |
| `matlab` 命令可执行 | 命令行 `matlab -version` 成功 |
| 环境变量 | `MEDIMAGE_ENABLE_REVIEWED_EXECUTION=1` |
| 后端启动 | `uvicorn src.backend.app.main:app --host 127.0.0.1 --port 8000` |
| Python 依赖 | `pip install -r requirements.txt` |

```bash
# 验证 MATLAB
matlab -batch "disp('MATLAB OK'); exit(0);"

# 设置环境变量
export MEDIMAGE_ENABLE_REVIEWED_EXECUTION=1
```

---

## 二、project_config

创建 `spm_smoke_config.yaml`:

```yaml
project:
  name: spm_smoke_validation
  description: "SPM smoke test manual validation."

runtime:
  work_dir: ./outputs/work
  log_dir: ./outputs/logs
  derivatives_dir: ./outputs/derivatives
  report_dir: ./outputs/reports
  matlab_command: matlab

third_party:
  spm_dir: /path/to/your/spm12          # ← 修改为真实 SPM 路径
  dpabi_dir: /path/to/dpabi_or_dummy    # ← 可使用 dummy 路径

safety:
  rawdata_readonly: true
  allow_overwrite_derivatives: false
  require_confirmation: true
```

**重要**:
- `spm_dir` 必须指向真实 SPM12 根目录
- `matlab_command` 不能包含参数或 shell 字符
- `rawdata_readonly` 必须为 `true`
- `dpabi_dir` 可使用 dummy 路径 (spm_smoke_test 不调用 DPABI)

## 三、reviewed plan

只允许 `spm_smoke_test` — **禁止任何 subject-level SPM 节点**。

```json
{
  "pipeline_id": "spm_smoke_reviewed",
  "nodes": [
    {
      "id": "spm_smoke_test",
      "backend": "matlab-spm",
      "depends_on": [],
      "params": {}
    }
  ]
}
```

### 禁止的节点

| Node ID | 原因 |
|---------|------|
| `spm_realign_subject` | subject-level — 阻断 |
| `spm_slice_timing_subject` | subject-level — 阻断 |
| `spm_coregister_subject` | subject-level — 阻断 |
| `spm_segment_subject` | subject-level — 阻断 |
| `spm_normalize_subject` | subject-level — 阻断 |
| `spm_smooth_subject` | subject-level — 阻断 |
| 任何 `dpabi_*` | DPABI — 阻断 |
| 任何 `gui_*` | GUI — 阻断 |

## 四、approval

**必须** 使用 explicit node + backend approval。

### ✅ 正确写法

```json
{
  "approved": true,
  "approved_by": "local-user",
  "reason": "Manual SPM smoke validation.",
  "approved_nodes": ["spm_smoke_test"],
  "approved_backends": ["matlab-spm"],
  "rejected_nodes": [],
  "review_draft_schema_version": "review-draft-v1"
}
```

### ❌ 不允许的写法

```json
// wildcard — 被 M6-T003 阻断
{
  "approved": true,
  "approved_nodes": ["*"],
  "approved_backends": ["matlab-spm"]
}

// 缺少 approved_backends — 被 M6-T003 阻断
{
  "approved": true,
  "approved_nodes": ["spm_smoke_test"]
}

// 缺少 node approval — 被 M6-T003 阻断
{
  "approved": true,
  "approved_nodes": [],
  "approved_backends": ["matlab-spm"]
}
```

## 五、API 调用

### curl

```bash
curl -s -X POST http://127.0.0.1:8000/api/plans/execute-reviewed \
  -H "Content-Type: application/json" \
  -d '{
    "plan": {
      "pipeline_id": "spm_smoke_reviewed",
      "nodes": [{"id": "spm_smoke_test", "backend": "matlab-spm", "depends_on": [], "params": {}}]
    },
    "approval": {
      "approved": true,
      "approved_by": "local-user",
      "approved_nodes": ["spm_smoke_test"],
      "approved_backends": ["matlab-spm"],
      "rejected_nodes": []
    },
    "project_config_path": "spm_smoke_config.yaml",
    "dry_run": false,
    "confirm_execution": true,
    "persist_audit": true,
    "write_pipeline_yaml": true,
    "actor": "spm-smoke-manual"
  }' | python -m json.tool
```

### 关键字段

| 字段 | 值 | 说明 |
|------|-----|------|
| `dry_run` | `false` | 真实执行 |
| `confirm_execution` | `true` | 必须二次确认 |
| `persist_audit` | `true` | 审计记录必须写入 |
| `write_pipeline_yaml` | `true` | pipeline YAML 必须写入 |

## 七、失败诊断

### 状态诊断表

| 状态 | 可能原因 | 如何检查 | 修复 |
|------|---------|---------|------|
| `REVIEWED_EXECUTION_DISABLED` | env var 未设置 | `echo $MEDIMAGE_ENABLE_REVIEWED_EXECUTION` | `export MEDIMAGE_ENABLE_REVIEWED_EXECUTION=1` |
| `CONFIRMATION_REQUIRED` | `confirm_execution` 未 true | 检查请求 body | 设置 `"confirm_execution": true` |
| `AUDIT_REQUIRED` | `persist_audit` 未 true | 检查请求 body | 设置 `"persist_audit": true` |
| `PROJECT_CONFIG_REQUIRED` | `project_config_path` 缺失 | 检查请求 body | 填写 config 路径 |
| `PROJECT_CONFIG_INVALID` | config YAML 格式错误 | 手动检查 YAML 语法 | 修正 YAML |
| `VALIDATION_FAILED` | node 不在 Tool Catalog | 检查 node id 拼写 | 只用 `spm_smoke_test` |
| `APPROVAL_GATE_BLOCKED` | wildcard 或缺少 backend approval | 检查 `approved_nodes` + `approved_backends` | 使用 explicit node + backend |
| `PLAN_ADAPTER_FAILED` | plan 结构错误 | 检查 node depends_on | 修正 plan |
| `EXECUTION_POLICY_BLOCKED` | 包含 subject-level SPM | 检查 nodes 列表 | 只用 `spm_smoke_test` |
| `SAFE_EXECUTION_POLICY_BLOCKED` | 包含 GPU/contract 节点 | 检查 nodes | 只用 Python + smoke |
| `PIPELINE_YAML_REQUIRED` | `write_pipeline_yaml` 未 true | 检查请求 body | 设置 `"write_pipeline_yaml": true` |
| `PIPELINE_WRITE_FAILED` | writer 异常 | 检查 `outputs/work/` 权限 | 确认目录可写 |
| `AUDIT_WRITE_FAILED` | audit 写入失败 | 检查 `outputs/reports/` 权限 | 确认目录可写 |
| `EXECUTION_FAILED` | MATLAB/SPM 调用失败 | 检查 `outputs/logs/` | 见下方 MATLAB diagnostics |

### MATLAB safety diagnostics

| Warning/Error | Severity | 原因 | 检查 |
|---------------|:---:|------|------|
| `MATLAB_COMMAND_NOT_FOUND` | ⚠️ warning | `matlab` 不在 PATH | `which matlab` |
| `MATLAB_COMMAND_HAS_ARGUMENTS` | 🔴 error | command 包含空格/参数 | 只用 `matlab` |
| `MATLAB_COMMAND_FORBIDDEN_CHAR` | 🔴 error | command 包含 `; & \|` 等 | 只用 `matlab` |
| `MATLAB_COMMAND_INVALID_BASENAME` | 🔴 error | 不是 matlab/matlab.exe | 修正 command |
| `THIRD_PARTY_DIR_NOT_FOUND` | ⚠️ warning | SPM/DPABI 路径不存在 | 检查 `spm_dir` |
| `THIRD_PARTY_DIR_FORBIDDEN_LOCATION` | 🔴 error | 指向 rawdata/derivatives 等 | 修正路径 |

**Warning 不阻断 execution，但表示可能的环境问题。
Error 必须修复才能进入 execution。**

### 成功执行后

```bash
# Pipeline YAML
ls outputs/work/reviewed_pipelines/
# → reviewed_spm_smoke_*.yaml

# Audit records
ls outputs/reports/audit_records/
# → audit_*.json

# SPM smoke output
ls outputs/work/spm_smoke_test/
# → result.json, smoothed.nii (如果 MATLAB 成功)

# Logs
ls outputs/logs/
# → spm_smoke_test_stdout.log, spm_smoke_test_stderr.log
```

### 确认安全

| 检查 | 命令 | 预期 |
|------|------|------|
| rawdata 未修改 | `git status data/` | 空 |
| derivatives 未被意外写入 | `find outputs/derivatives -newer <pre-run-time>` | 空 |
| 输出在受控目录 | `find outputs/ -maxdepth 3` | 仅 work/reports/logs |

## 九、清理

```bash
# 清理 SPM smoke 产物
rm -rf outputs/work/spm_smoke_test/
rm -rf outputs/work/reviewed_pipelines/reviewed_spm_smoke_*.yaml
rm -rf outputs/reports/audit_records/audit_*.json

# 清理 logs
rm -f outputs/logs/spm_smoke_test_*.log

# 移除环境变量
unset MEDIMAGE_ENABLE_REVIEWED_EXECUTION
```

**不要删除 `data/`、`rawdata/`、`derivatives/`、`reports/` 中的非 smoke 产物。**
