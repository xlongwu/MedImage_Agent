# Native Preprocessing Function Coverage Matrix

Status: Phase 01 contract baseline with current implementation note.

This matrix maps SPM/DPABI source capabilities to planned Python-native target
modules. Reuse strategy is intentionally closed to:

- `clean_room_rewrite`
- `behavior_reference_only`
- `golden_output_reference`
- `not_needed`
- `defer`

The matrix does not authorize native runtime execution of MATLAB, SPM, DPABI,
or `third_party/**/*.m`.

Current implementation note: as of 2026-06-28 the native full runner and
reviewed/default native workflow are implemented, but this matrix remains a
source-to-target coverage and validation-boundary document. Entries marked
`golden_output_reference` do not mean SPM/DPABI golden reference validation has
been completed.
