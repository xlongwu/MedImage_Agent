# 临时任务目录

此目录用于存储后续 Codex 开发的临时任务交接文档（handoff
files）。具体任务文件（`TASK_*.md`）应在任务完成后删除或迁移到正确的长期文档。

历史 Agent 输出、提示词集合和已经实施完成的方案不在本目录长期保留。
其中具有持久价值的信息应迁移到架构文档、ADR、发布说明或
`specs/阶段记录/`；其余内容在任务完成后删除。

## 目录结构

| 文件 | 用途 | 版本控制 |
|---|---|---|
| `README.md` | 本说明文档 | ✅ tracked |
| `TASK_TEMPLATE.md` | 任务文件模板 | ✅ tracked |
| `TASK_*.md` | 具体任务文件（临时） | ❌ ignored |

## 任务文件生命周期

1. 创建 `TASK_<id>.md` — 记录任务需求、设计决策和实现细节
2. 实现完成后 — 将持久化信息迁移到正确的长期文档（如架构文档、ADR、release notes）
3. 迁移完成后 — 删除 `TASK_*.md`

**禁止：** 任务文件无限期累积。已完成的任务交接不应残留在此目录。

## 模板使用

复制 `TASK_TEMPLATE.md` 并以 `TASK_<简短描述>.md` 命名，或使用编号 `TASK_001.md` 格式。
