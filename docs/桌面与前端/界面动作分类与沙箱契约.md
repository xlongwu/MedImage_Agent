## 1. Scope and Non-Goals

### Scope

- Define the complete GUI/manual action taxonomy across four risk tiers (0–3).
- Define per-tier risk level, approval requirements, allowed conditions, and default status.
- Define the GUI session sandbox declaration schema with every field meaning, allowed values, blocked values, and rationale.
- Define the per-action declaration schema for individual GUI steps.
- Define provider policy contracts: MockGuiProvider, PyWinAutoGuiProvider, CI.
- Define screenshot, clipboard, file/path, network, and external application/window policy contracts.
- Define the blocked action contract — an explicit blocklist with reasons.
- Define future policy classification rules (pseudocode) for plan_adapter / API guard integration.
- Provide the test basis for M9-GUI-T004 (blocklist and policy tests).

### Non-Goals

- Implementing GUI automation, enabling PyWinAuto provider, calling GUI automation libraries.
- Changing `/api/gui-agent/*` behavior, registering GUI nodes, modifying the allowlist.
- Modifying `approval_gate.py`, `plan_adapter.py`, `execute_reviewed_routes.py`, or `pipeline_executor.py`.
- Modifying `NODE_REGISTRY` or `TOOL_METADATA`.
- Opening any reviewed execution path for GUI/manual nodes.
- Implementing GUI tests — T003 is a contract design document; tests come in T004.

## 3. GUI Action Taxonomy

### 3.1 Overview

Every GUI action is classified into exactly one of four risk tiers. The tier determines approval requirements, allowed providers, and whether the action is enabled by default or blocked.

```
Tier 0 ─ read-only observation      (safest)
Tier 1 ─ low-risk navigation
Tier 2 ─ medium-risk interaction     (requires structured approval)
Tier 3 ─ high-risk / blocked by default  (requires separate contract)
```

### 3.2 Tier 0 — Read-Only Observation

**Risk**: Low  
**Default**: Allowed with valid session declaration  
**Real desktop**: Requires session approval  

| Action ID | Description | Current in `gui_agent.py`? |
|-----------|-------------|:---:|
| `record_observation` | Record an observed UI state without any interaction | ✅ (`record_observation`) |
| `get_window_title` | Read the title text of the target window | ✅ (via `window.window_text()`) |
| `list_windows` | Enumerate visible top-level windows and their titles | ❌ (not yet — safe to add) |
| `screenshot_ephemeral` | Capture screenshot for real-time human review; no persistence | ✅ (via `capture_screenshot`, but needs ephemeral variant) |
| `observe_visible_ui_state` | Read control labels, button text, menu items visible on screen | ❌ (not yet — safe to add) |
| `record_mock_observation` | Mock-only: record intended observation without any real window access | ✅ (MockGuiProvider default) |

**Policy**:

| Field | Value |
|-------|-------|
| Mock provider | Allowed unconditionally (CI safe) |
| Real provider | Requires valid session declaration with `provider=pywinauto` + `gui_sandbox_mode=true` |
| Persistent screenshot | Disabled by default; `screenshot_policy` must be `ephemeral_only` |
| Clipboard access | Prohibited |
| File writes | Prohibited |
| Keyboard input | Prohibited |
| Mouse input | Prohibited |
| Audit | Required |

**Stop conditions**: unexpected_application, permission_dialog, credential_field

| Per-action confirmation | **INSUFFICIENT WITHOUT SEPARATE CONTRACT** |
| Separate safety contract | **REQUIRED** before any Tier 3 action can be considered for real provider |
| Credential entry | **PERMANENTLY BLOCKED** |
| OS security dialog acceptance | **PERMANENTLY BLOCKED** |
| Email/messaging | **PERMANENTLY BLOCKED** |

## 4. Action Tier to Approval Mapping

| Tier | Risk | Examples | Session Approval | Action-Plan Approval | Per-Action Confirmation | Mock Default | Real Default |
|:---:|:---:|------|:---:|:---:|:---:|:---:|:---:|
| **0** | Low | `record_observation`, `get_window_title`, `screenshot_ephemeral` | ✅ Required | ❌ Not required | ❌ Not required | ✅ Allowed | ⚠️ With session approval |
| **1** | Low | `focus_window`, `switch_tab`, `wait_for_window` | ✅ Required | ❌ Not required | ❌ Not required | ✅ Allowed | ⚠️ Within declared window/app |
| **2** | Medium | `fill_form_field_non_secret`, `select_file_scoped`, `click_dry_run` | ✅ Required | ✅ Required | ⚠️ Required if side effects possible | ✅ Allowed (dry-run) | ⚠️ All 3 layers required |
| **3** | High/Critical | `click_run`, `enter_credentials`, `launch_external_app` | ❌ Insufficient | ❌ Insufficient | ❌ Insufficient | ⚠️ Mock only (contract design) | ❌ **BLOCKED** |

**Legend**:
- ✅ Required = Must be present for execution to proceed
- ❌ Not required = Not needed at this tier
- ❌ Insufficient = Even with this approval, execution is blocked — stronger gating needed
- ⚠️ = Conditional

**Key Principle**: Higher tiers do NOT inherit approval from lower tiers. A Tier 2 action cannot be executed with only Tier 0 session approval.

## 5. GUI Session Sandbox Declaration Schema

### 5.1 Schema

```json
{
  "$schema": "medimage-gui-session-declaration-v1",
  "gui_sandbox_mode": true,
  "session_id": "gui_abc123def456",
  "provider": "mock",
  "target_application": "MATLAB",
  "target_window": "SPM.*Batch Editor",
  "allowed_action_tiers": [0, 1],
  "file_scope": [
    "outputs/work/gui_agent/",
    "reports/gui/"
  ],
  "allow_rawdata_access": false,
  "allow_derivatives_write": false,
  "screenshot_policy": "ephemeral_only",
  "clipboard_policy": "disabled",
  "network_policy": "disabled",
  "external_app_policy": "declared_target_only",
  "duration_limit_seconds": 300,
  "step_limit": 20,
  "human_present": true,
  "emergency_abort_enabled": true,
  "audit_log_required": true,
  "redaction_policy": "required_for_persistence"
}
```

### 5.2 Field Definitions

#### `gui_sandbox_mode` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Declares this session operates under the GUI sandbox declaration contract. The session is a sandbox execution, not unrestricted desktop control. |
| **Type** | `boolean` |
| **Allowed** | `true` |
| **Blocked** | `false`, missing, null |
| **Default** | Must be explicitly set; no default |
| **Why it matters** | Without `gui_sandbox_mode=true`, the session is treated as unrestricted — which is blocked. This is the first gate. If a session declaration is missing this field or sets it to `false`, the entire session is rejected. |

#### `session_id` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Unique identifier for this GUI session. Used for audit trail and abort targeting. |
| **Type** | `string` |
| **Allowed** | Alphanumeric + `_` + `-`, max 64 chars |
| **Blocked** | Path traversal characters (`/`, `\\`, `..`), empty string |
| **Default** | Auto-generated if not provided (as in `_stable_session_id()`) |
| **Why it matters** | Session ID is used as a directory name. Path traversal would allow writing outside the sandbox. |

#### `provider` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Which GUI provider backend to use. |
| **Type** | `string` (enum) |
| **Allowed** | `"mock"` (always), `"pywinauto"` (only with explicit real-provider policy) |
| **Blocked** | Any value not in `SUPPORTED_PROVIDERS`, `"pywinauto"` without `MEDIMAGE_GUI_AGENT_REAL_PROVIDER=1` |
| **Default** | `"mock"` |
| **Why it matters** | Provider determines whether the session controls a real desktop. Mock is safe by default. PyWinAuto requires multiple additional gates. |

#### `target_application` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | The human-readable name of the application the GUI agent will interact with. |
| **Type** | `string` |
| **Allowed** | `"MATLAB"`, `"SPM"`, `"DPABI"` (initial allowlist); others require separate contract |
| **Blocked** | `"Browser"`, `"Explorer"`, `"cmd"`, `"powershell"`, `"Outlook"`, `"Thunderbird"`, `"Slack"`, `"Teams"`, empty string, wildcard (`"*"`, `"any"`) |
| **Default** | Must be explicitly declared; no default |
| **Why it matters** | Different applications have different risk profiles. MATLAB/SPM/DPABI are the only declared targets for rs-fMRI GUI assistance. Browser/email/terminal/IDE control is permanently blocked. |

#### `target_window` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | A regex pattern matching the window title the agent will interact with. |
| **Type** | `string` (regex) |
| **Allowed** | Specific window patterns like `"SPM.*Batch Editor"`, `"DPABI.*"` |
| **Blocked** | `".*"`, `""`, patterns that match browser windows, file explorers, terminals, or system dialogs |
| **Default** | Must be explicitly declared; if absent, falls back to `target_app` pattern (current behavior — should be tightened) |
| **Why it matters** | Prevents the agent from interacting with windows outside the declared scope. An unexpected window must trigger a stop. |

#### `allowed_action_tiers` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Which risk tiers of actions are permitted in this session. |
| **Type** | `array` of `integer` |
| **Allowed** | `[0]`, `[0, 1]`, `[0, 1, 2]` |
| **Blocked** | `[3]`, `[0, 1, 2, 3]`, any array containing `3`, empty array `[]` |
| **Default** | `[0]` (safest) |
| **Why it matters** | Tier 3 actions are blocked by default. A session cannot declare itself as Tier-3-capable without a separate safety contract. |

#### `file_scope` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | The set of directories within which file access (read, select, write) is permitted. |
| **Type** | `array` of `string` (paths, relative to project root) |
| **Allowed** | `["outputs/work/gui_agent/"]`, `["reports/gui/"]` |
| **Blocked** | `["/"]`, `["C:\\"]`, `["data/"]`, `["~"]`, `["."]`, empty array, any path containing `..` |
| **Default** | `["outputs/work/gui_agent/"]` |
| **Why it matters** | Prevents the agent from reading or writing files outside the GUI agent sandbox. Rawdata, derivatives, home directory, and system paths are blocked. |

#### `allow_rawdata_access` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Whether the session is permitted to access files under `data/` (rawdata). |
| **Type** | `boolean` |
| **Allowed** | `false` |
| **Blocked** | `true` |
| **Default** | `false` |
| **Why it matters** | Rawdata is the read-only invariant. GUI agent must never access raw BIDS data directly. |

#### `allow_derivatives_write` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Whether the session is permitted to write files under `outputs/derivatives/`. |
| **Type** | `boolean` |
| **Allowed** | `false` (default) |
| **Blocked** | `true` (unless future separate contract for GUI-initiated derivative writes) |
| **Default** | `false` |
| **Why it matters** | Derivatives writes are destructive to pipeline outputs. GUI agent should not overwrite derivatives without an explicit, reviewed sandbox contract. |

#### `screenshot_policy` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Controls whether screenshots can be captured, and if so, whether they can be persisted. |
| **Type** | `string` (enum) |
| **Allowed** | `"disabled"`, `"ephemeral_only"`, `"persist_redacted"` |
| **Blocked** | `"persist_raw"`, `"unrestricted"`, any value not in allowed list |
| **Default** | `"disabled"` |
| **Why it matters** | Screenshots can contain medical data, credentials, file paths, and browser content. Raw persistence is never allowed. |

Detailed rules in §8 (Screenshot Policy Contract).

#### `clipboard_policy` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Controls whether the agent can read from or write to the system clipboard. |
| **Type** | `string` (enum) |
| **Allowed** | `"disabled"` |
| **Blocked** | `"read_only"`, `"write_only"`, `"read_write"`, `"unrestricted"` |
| **Default** | `"disabled"` |
| **Why it matters** | Clipboard can contain passwords, tokens, medical data, and private text. Clipboard access is high-risk and blocked by default. |

Detailed rules in §9 (Clipboard Policy Contract).

#### `network_policy` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Controls whether the agent can access the network. |
| **Type** | `string` (enum) |
| **Allowed** | `"disabled"`, `"local_only"` |
| **Blocked** | `"unrestricted"`, `"upload"`, `"download"`, `"external_submission"` |
| **Default** | `"disabled"` |
| **Why it matters** | Network access enables data exfiltration, downloading untrusted content, and submitting sensitive data to external servers. |

Detailed rules in §11 (Network Policy Contract).

#### `external_app_policy` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Controls whether the agent can interact with applications other than the declared target. |
| **Type** | `string` (enum) |
| **Allowed** | `"declared_target_only"` |
| **Blocked** | `"any_app"`, `"allowlisted_apps"` (until future contract), `"any_window"` |
| **Default** | `"declared_target_only"` |
| **Why it matters** | Switching to browser, email, terminal, or file explorer constitutes a safety boundary violation. |

Detailed rules in §12 (External App/Window Policy Contract).

#### `duration_limit_seconds` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Maximum wall-clock duration for the entire session. After this, the session auto-aborts. |
| **Type** | `integer` |
| **Allowed** | 1–600 (10 minutes max per session) |
| **Blocked** | 0, negative values, >600 |
| **Default** | `300` (5 minutes) |
| **Why it matters** | Prevents unattended long-running GUI sessions. Bounded duration is a safety invariant. |

#### `step_limit` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Maximum number of action steps in this session. After this, the session auto-aborts. |
| **Type** | `integer` |
| **Allowed** | 1–50 |
| **Blocked** | 0, negative values, >50 |
| **Default** | `20` |
| **Why it matters** | Prevents unlimited action sequences. Bounded step count is a safety invariant. |

#### `human_present` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Declaration that a human operator is present and monitoring the session. |
| **Type** | `boolean` |
| **Allowed** | `true` |
| **Blocked** | `false` (real provider cannot run unattended) |
| **Default** | Must be explicitly set; if `true`, real provider may proceed (with other gates); if `false`, real provider is blocked regardless of other gates |
| **Why it matters** | GUI agent must never run unattended with real desktop control. The human-present flag is a required safety declaration. |

#### `emergency_abort_enabled` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Whether the emergency abort mechanism is active for this session. |
| **Type** | `boolean` |
| **Allowed** | `true` |
| **Blocked** | `false` |
| **Default** | `true` |
| **Why it matters** | Emergency abort is non-negotiable. Every GUI session must have a kill switch. |

#### `audit_log_required` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Whether every action in this session must be audit-logged. |
| **Type** | `boolean` |
| **Allowed** | `true` |
| **Blocked** | `false` |
| **Default** | `true` |
| **Why it matters** | GUI actions are high-risk and must be fully auditable. No audit = no execution. |

#### `redaction_policy` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Whether sensitive data redaction is required before any persistent storage (screenshots, logs). |
| **Type** | `string` (enum) |
| **Allowed** | `"required_for_persistence"` |
| **Blocked** | `"none"`, `"optional"` |
| **Default** | `"required_for_persistence"` |
| **Why it matters** | Medical data, credentials, and file paths must be redacted from any persisted artifact. |

### 5.3 Session Validation Pseudocode

```python
def validate_gui_session_declaration(session: dict) -> tuple[bool, list[str]]:
    """Validate a GUI session sandbox declaration. Returns (ok, errors)."""
    errors = []

    # 1. gui_sandbox_mode must be explicitly true
    if session.get("gui_sandbox_mode") is not True:
        errors.append("gui_sandbox_mode must be true")
        return False, errors

    # 2. Provider validation
    provider = session.get("provider", "mock")
    if provider not in {"mock", "pywinauto"}:
        errors.append(f"Unsupported provider: {provider}")
    if provider == "pywinauto":
        if not _is_real_provider_enabled():
            errors.append("Real desktop provider requires MEDIMAGE_GUI_AGENT_REAL_PROVIDER=1")

    # 3. Target application must be declared and allowed
    target_app = session.get("target_application", "")
    if not target_app or target_app in BLOCKED_APPLICATIONS:
        errors.append(f"target_application blocked or missing: {target_app}")

    # 4. Target window required
    target_window = session.get("target_window", "")
    if not target_window or target_window in BLOCKED_WINDOW_PATTERNS:
        errors.append(f"target_window blocked or missing: {target_window}")

    # 5. Allowed action tiers must not include Tier 3
    tiers = session.get("allowed_action_tiers", [])
    if 3 in tiers:
        errors.append("Tier 3 actions are not allowed in sandbox mode")
    if not tiers:
        errors.append("allowed_action_tiers must not be empty")

    # 6. File scope validation
    file_scope = session.get("file_scope", [])
    if not file_scope:
        errors.append("file_scope must not be empty")
    for path in file_scope:
        if not _is_scoped_path(path):
            errors.append(f"File scope path outside sandbox: {path}")

    # 7. Rawdata / derivatives access
    if session.get("allow_rawdata_access") is True:
        errors.append("Rawdata access is not allowed")
    if session.get("allow_derivatives_write") is True:
        errors.append("Derivatives write requires separate contract")

    # 8. Screenshot policy
    screenshot_policy = session.get("screenshot_policy", "disabled")
    if screenshot_policy not in ALLOWED_SCREENSHOT_POLICIES:
        errors.append(f"Screenshot policy blocked: {screenshot_policy}")

    # 9. Clipboard policy
    clipboard_policy = session.get("clipboard_policy", "disabled")

        errors.append(f"Network policy blocked: {network_policy}")

    # 11. External app policy
    ext_policy = session.get("external_app_policy", "declared_target_only")
    if ext_policy != "declared_target_only":
        errors.append("External app policy must be declared_target_only")

    # 12. Duration and step limits
    duration = session.get("duration_limit_seconds", 0)
    if duration <= 0 or duration > 600:
        errors.append(f"Duration limit out of range: {duration}")
    steps = session.get("step_limit", 0)
    if steps <= 0 or steps > 50:
        errors.append(f"Step limit out of range: {steps}")

    # 13. Human present required for real provider
    if provider == "pywinauto" and session.get("human_present") is not True:
        errors.append("Real provider requires human_present=true")

    # 14. Emergency abort and audit are non-negotiable
    if session.get("emergency_abort_enabled") is not True:
        errors.append("emergency_abort_enabled must be true")
    if session.get("audit_log_required") is not True:
```

### 6.2 Field Definitions

#### `session_id` (required)

Must match an active, validated session declaration.

#### `step_id` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | Unique identifier for this step within the session. |
| **Allowed** | `"step_NNN"` where NNN is a zero-padded integer matching the step index |
| **Blocked** | Arbitrary strings, path characters |

#### `action_type` (required)

| Attribute | Value |
|-----------|-------|
| **Meaning** | The exact action being performed. Must be one of the defined action IDs in the taxonomy (§3). |
| **Allowed** | Any action ID from Tier 0, 1, 2 in §3.2–§3.4 |
| **Blocked** | Any action ID from Tier 3 (§3.5), undefined action IDs |

#### `action_tier` (required, computed)

| Attribute | Value |
|-----------|-------|
| **Meaning** | The risk tier of this action. **Must be computed or verified by the policy layer**, not self-declared by the caller. |
| **Allowed** | 0, 1, 2 (per session's `allowed_action_tiers`) |
| **Blocked** | 3 (regardless of session declaration), any value not matching `action_type`'s canonical tier |
| **Validation rule** | `classify_action_tier(action_type)` must equal `action_tier`. Mismatch → blocked. |

#### `target_application` (required)

Must match the session's `target_application`.

#### `target_window` (required)

Must be a subset of or match the session's `target_window` scope.

#### `parameters` (required)

Action-specific parameters. Each action type has a defined parameter schema:

| Action Type | Required Parameters | Optional Parameters |
|-------------|-------------------|-------------------|
| `focus_window` | `window_title` | — |
| `wait_for_window` | `window_title`, `timeout_seconds` | — |
| `wait` | `seconds` | — |
| `switch_tab` | `tab_name` | — |
| `scroll` | `direction`, `amount` | — |
| `fill_form_field_non_secret` | `field_identifier`, `text` | — |
| `select_file_under_scoped_directory` | `file_path` | — |
| `menu_select_read_only` | `menu_path` | — |
| `toggle_non_destructive_option` | `control_identifier` | — |
| `click_dry_run` | `control_identifier` | — |
| `screenshot_ephemeral` | — | `region` |
| `screenshot_persist_redacted` | — | `region`, `redaction_regions` |
| `record_observation` | `observation` | — |
| `get_window_title` | — | — |

**Blocked parameter values**:

- Any parameter value containing `..` (path traversal)
- `text` containing credential-like patterns (must be validated by policy layer)
- `file_path` outside session `file_scope`
- `window_title` matching a blocked window pattern
- `menu_path` containing execution triggers (must be validated)

#### `input_paths` / `output_paths` (required)

Must be within session `file_scope`. If empty, must be `[]`. Paths containing `..` are blocked.

#### `uses_screenshot` (required)

If `true`, session's `screenshot_policy` must allow it. If `false`, no screenshot APIs are called.

#### `uses_clipboard` (required)

If `true`, session's `clipboard_policy` must allow it. Currently always blocked (`clipboard_policy="disabled"`).

#### `uses_keyboard` / `uses_mouse` (required)

Must be consistent with `action_type`. For example, `fill_form_field_non_secret` → `uses_keyboard=true`, `focus_window` → both `false`.

#### `network_access` (required)

If `true`, session's `network_policy` must allow it. Tier 0/1 actions should always have `false`.

#### `expected_side_effects` (required)

Human-readable description of what will change. Must not be empty.

#### `requires_per_action_confirmation` (required, computed)

`true` for Tier 2 actions with side effects. `false` for Tier 0/1. Must match the tier's canonical confirmation requirement.

#### `confirmation_id` (conditional)

If `requires_per_action_confirmation=true`, this must reference a valid, confirmed `confirmation_id` from the approval system.

#### `rollback_plan` (required)

Human-readable description of how to undo this action if it fails. If no undo is possible, must state that explicitly.

#### `stop_conditions` (required)

List of conditions that should abort the session. Minimum required: `["unexpected_application", "unexpected_window", "permission_dialog", "credential_field"]`.

### 6.3 Action Validation Pseudocode

```python
def validate_gui_action_declaration(
    action: dict,
    session: dict,
) -> tuple[bool, list[str]]:
    """Validate a GUI action declaration against its session. Returns (ok, errors)."""
    errors = []

    # 1. Session must be valid and active
    if session.get("status") in ("ABORTED", "EXPIRED"):
        errors.append(f"Session is {session['status']}")
        return False, errors

    # 2. action_type must be a known type
    action_type = action.get("action_type")
    tier = ACTION_TIER_MAP.get(action_type)
    if tier is None:
        errors.append(f"Unknown action_type: {action_type}")
        return False, errors

    # 3. Tier must match canonical tier
    declared_tier = action.get("action_tier")
    if declared_tier != tier:
        errors.append(f"action_tier mismatch: declared {declared_tier}, canonical {tier}")

    # 4. Tier 3 is always blocked
    if tier == 3:
        errors.append(f"Tier 3 action blocked: {action_type}")
        return False, errors

    # 5. Tier must be within session's allowed tiers
    allowed_tiers = session.get("allowed_action_tiers", [0])
    if tier not in allowed_tiers:
        errors.append(f"Action tier {tier} not in session allowed tiers {allowed_tiers}")

    # 6. Provider-specific checks
    provider = session.get("provider", "mock")
    if provider == "pywinauto" and tier >= 2:
        if not action.get("requires_per_action_confirmation"):
            errors.append("Tier 2+ action with real provider requires per_action_confirmation")
        if not action.get("confirmation_id"):
            errors.append("Tier 2+ action with real provider requires confirmation_id")

    # 7. Screenshot policy check
    if action.get("uses_screenshot"):
        policy = session.get("screenshot_policy", "disabled")
        if policy == "disabled":
            errors.append("Screenshot usage blocked by session screenshot_policy=disabled")

    # 8. Clipboard policy check
    if action.get("uses_clipboard"):
        policy = session.get("clipboard_policy", "disabled")
        if policy != "read_once_confirmed" and policy != "write_once_confirmed":
            errors.append("Clipboard usage blocked by session clipboard_policy")

    # 9. File path scope check
    for path in (action.get("input_paths") or []) + (action.get("output_paths") or []):
        if not _path_within_scope(path, session.get("file_scope", [])):
            errors.append(f"File path outside session scope: {path}")

    # 10. Network check
    if action.get("network_access"):
        policy = session.get("network_policy", "disabled")
        if policy == "disabled":
            errors.append("Network access blocked by session network_policy=disabled")

    # 11. Side effects must be declared
    if not action.get("expected_side_effects"):
        errors.append("expected_side_effects must be declared")

    # 12. Stop conditions must include minimum set
    stop_conditions = action.get("stop_conditions", [])
    required_stops = {"unexpected_application", "credential_field"}
    missing = required_stops - set(stop_conditions)
    if missing:
        errors.append(f"Missing required stop conditions: {missing}")

    # 13. Target application/window must match session
    if action.get("target_application") != session.get("target_application"):
        errors.append("target_application does not match session")

    return len(errors) == 0, errors
```

## 8. Screenshot Policy Contract

### 8.1 Allowed Values

| Value | Meaning | Persistence | Redaction Required | Default |
|-------|---------|:---:|:---:|:---:|
| `"disabled"` | No screenshots can be captured | N/A | N/A | ✅ |
| `"ephemeral_only"` | Screenshots captured for real-time human review only; deleted after session close | No | Not required (not stored) | — |
| `"persist_redacted"` | Screenshots persisted but sensitive regions must be redacted first | Yes | Yes (before storage) | — |

### 8.2 Blocked Values

| Value | Reason |
|-------|--------|
| `"persist_raw"` | Raw screenshots can contain medical images, credentials, file paths, PHI |
| `"unrestricted"` | No policy = no safety |

### 8.3 Rules

1. Screenshots are **sensitive by default**. They can contain medical images (BOLD slices, T1w anatomy), MATLAB command window output (paths, subject IDs), file dialogs (filesystem structure), and dialog boxes (error messages with paths).
2. `ephemeral_only` is preferred for any real-provider session. The screenshot is streamed to the human operator for confirmation but not written to disk.
3. `persist_redacted` requires:
   - A redaction pipeline that identifies and masks: credential fields, file paths, subject IDs, medical image regions, browser content, email addresses, API keys.
   - Explicit per-screenshot approval.
   - Audit log entry recording the redaction applied.
4. Screenshots containing credentials, PHI, tokens, rawdata paths, or private browser content must **never** be persisted, even with redaction — they must be rejected at capture time.
5. Mock provider screenshots are `.txt` placeholders and are not subject to the same policy (no real pixels).

### 14.3 Classification Pseudocode

```python
def classify_gui_action(action_type: str) -> str:
    """Classify a GUI action into a policy category."""
    tier = ACTION_TIER_MAP.get(action_type)
    if tier is None:
        return "blocked_unknown_action"

    if tier == 3:
        return "blocked_tier_3"

    features = ACTION_FEATURES.get(action_type, {})

    if features.get("clipboard"):
        return "blocked_clipboard_access"

    if features.get("network"):
        return "blocked_network_access"

    if features.get("keyboard") and action_type not in ("fill_form_field_non_secret",):
        return "blocked_keyboard_input"

    if features.get("file_write") and tier < 2:
        return "blocked_file_write_at_low_tier"

    if tier == 0:
        return "allowed_tier_0_read_only"

    if tier == 1:
        return "allowed_tier_1_navigation"

    if tier == 2:
        return "allowed_tier_2_interaction_requires_approval"

    return "blocked_unclassified"
```
