# Group-level Dataset Summary and Dashboard Specification

Read-only aggregation of all subject-level QC, metrics, contracts, and pipeline runs into a cross-subject dashboard. Discovers subjects from derivatives subdirectories. Produces dataset_summary.json, dashboard_data.json, subject_metrics_table.csv, pipeline_completeness.json, contracts_overview.json, and Markdown report. No SPM/MATLAB/DPABI/GPU execution.
