                  │                 │                ▲
                  │                 │ golden test    │ (任意状态
                  │                 ▼                │  均可转换)
                  │        ┌──────────────┐          │

**允许转换规则**（`_ALLOWED_TRANSITIONS`）：

```python
_ALLOWED_TRANSITIONS: dict[ExecutionStatus, set[ExecutionStatus]] = {
    ExecutionStatus.PLANNED:              {ExecutionStatus.SANDBOX_PREPARED, ExecutionStatus.FAILED},
    ExecutionStatus.DRY_RUN_READY:        {ExecutionStatus.SANDBOX_PREPARED, ExecutionStatus.FAILED},

```
